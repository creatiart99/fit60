# FIT60 — Draft visual v2

Marca: FIT60 · Coach Villa

## Abrir

Abre `index.html` en Chrome, Safari o Firefox. También puedes subir el contenido de esta carpeta a GitHub Pages para tener una URL pública de revisión.

## Pantallas

El selector superior **Coach Villa / Alumno** cambia entre dos sistemas visuales, tal como en las referencias: dashboard analítico claro con sidebar negra (coach), aplicación oscura con acento lima (alumno).

Coach: Resumen, Alumnos, Programas, Editor semanal, Alimentación, Actividad.
Alumno: Inicio, Entrenar, Comidas, Mi semana, Progreso.

## Interacciones de prueba

1. En Coach Villa, abre Programas, entra a Editar.
2. En el editor, pulsa Editar entrenamiento, modifica el nombre y guarda.
3. Cambia a Alumno y comprueba el ajuste en su vista.
4. Si seleccionas otro alumno desde la tabla, el mismo cambio no afecta a su plan.

## Estado del proyecto

Este es **un prototipo HTML visual**, no una plataforma en producción. Contiene datos ficticios. Las acciones de publicación/asignación/pagos requieren backend y control de usuarios antes de ser reales. Algunos cambios de demostración viven en la memoria de la página hasta recargar.

Las fotografías de ejemplo son imágenes fotográficas enlazadas desde Unsplash y necesitan Internet; no se han generado imágenes con IA. Sustituiremos estos placeholders por fotos y videos reales de Coach Villa y sus alumnos, con permisos. Logo y favicon proceden del archivo FIT60 facilitado.

La estructura es HTML + CSS + JavaScript sin frameworks para que se pueda revisar, modificar y subir a GitHub con facilidad.

## Publicación

El sitio está listo para publicarse desde la carpeta raíz de la rama `main` mediante GitHub Pages (Settings → Pages → Deploy from a branch → main → /root).
